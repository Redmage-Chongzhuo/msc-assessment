3. Background execution
-----------------------

Bash commands may execute in several modes:

- normal foreground execution
- explicit background execution through run_in_background
- timeout-triggered background execution
- user-triggered background execution
- assistant-mode automatic backgrounding

The assistant-mode blocking budget is:
- 15000 ms
- 15 seconds

After this threshold, an eligible command may be moved to the background.

Background tasks are registered through:
- spawnShellTask(...)
- backgroundExistingForegroundTask(...)

Background tasks can be disabled through:
- CLAUDE_CODE_DISABLE_BACKGROUND_TASKS

5. Final operating-system process call
--------------------------------------

src/utils/Shell.ts:316
- The final operating-system process is created through:

Static process configuration includes:
- executable binary

- current working directory
- environment variables
- stdin/stdout/stderr mode
- detached mode
- windowsHide

Important environment values include:
- SHELL
- GIT_EDITOR=true
- CLAUDECODE=1
- optional CLAUDE_CODE_SESSION_ID
- provider-specific overrides

The AbortSignal is not passed directly to spawn.
The implementation handles process-tree termination itself.

----------------------

8. Important static-analysis implications
-----------------------------------------

A scanner should distinguish between:
- the model-facing Bash tool call
- the shell abstraction call
- the final Node.js process spawn

Reporting only spawn(...) would lose:
- the original command string
- model-facing tool metadata
- timeout configuration
- background intent
- sandbox settings

Reporting only BashTool.call(...) would not identify:
- the actual operating-system process creation
- executable and argument construction
- working directory
- environment configuration

The analyser may therefore need linked findings or a call chain.

9. Runtime information still required
-------------------------------------

Static analysis cannot determine:
- actual execution count
- actual duration
- peak memory use
- CPU utilisation
- disk I/O
- stdout and stderr size
- whether automatic backgrounding occurred
- whether the command was interrupted
- actual child-process tree
- hardware energy use

These values would require runtime instrumentation.
