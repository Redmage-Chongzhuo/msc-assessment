5. Important static-analysis implications
-----------------------------------------

A scanner cannot rely only on direct calls to:
- anthropic.beta.messages.create(...)

The complete call chain is:

queryLoop(...)
→ deps.callModel(...)
→ productionDeps()
→ queryModelWithStreaming(...)
→ queryModel(...)
→ anthropic.beta.messages.create(...)

The analyser therefore needs to consider:
- SDK call recognition
- wrapper functions
- object-property function bindings
- dependency injection
- call purpose
- streaming and non-streaming modes
- statically visible parameters
- unresolved runtime values
